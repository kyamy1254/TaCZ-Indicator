# TaCZ Indicator (Minecraft Forge 1.20.1)

Minecraft Forge 1.20.1 向けの視認性・操作性に優れたダメージインジケータMODです。
特に **TaCZ (Timeless and Classics Zero)** のフルオート射撃や長距離狙撃に対応し、**「HUDレイヤーでの鮮明な表示」**、**「連続射撃の加算（スタック）/ 上方はけ（スクロール）」**、および **「武器別戦闘統計 (Weapon Breakdown)」** 機能を提供します。

---

## 主な特徴

- 🖥️ **HUD 2D レンダリング**: 3Dワールド座標から2D画面座標への投影により、HUDレイヤー上にクリアで美麗なダメージ数値を描画。
- 💥 **連続ダメージの加算表示 (Accumulation)**: フルオート連射や連続ヒット時にダメージがリアルタイムに合算され、爽快なヒットパルス演出。
- 📜 **古いインジケータの上方スクロール (Scroll Up)**: 連射時に古いダメージ値が上へスムーズにはけていき、画面の見やすさを維持。
- 🎯 **距離非依存レンダリング**: 500m先のスナイピングでも至近距離でも、画面上で常に一定の見やすいサイズでダメージ数を表示。
- 🔫 **武器別キル・ダメージ統計 (Weapon Breakdown)**: AK-47やM4A1、剣や弓など武器ごとの総ダメージ、命中数、HS率、AP数、キル数、最長キル距離を集計。
- ☠️ **武器名付きキル確定通知**: `Killed ゾンビ [AK-47] [100m]` のように武器名と距離を表示。
- 📊 **リアルタイムDPSメーター & 詳細戦闘統計画面 (`J`キー)**: 総合概要・武器別統計・キル履歴の3タブ切り替えおよびクリップボードへのレポートコピー完備。
- ⚙️ **充実したカスタマイズ (`K`キー)**: 描画モード、アニメーション、カラーテーマ（Default/Apex/Cyberpunk/Tactical/Valorant）、被ダメ赤色ヴィネット効果、サウンド等をGUIで設定可能。

---

## 操作キー (デフォルト設定)

| キー | 機能 |
| :---: | :--- |
| **`K`** | 設定GUI画面を開く (`IndicatorConfigScreen`) |
| **`J`** | 詳細戦闘統計・武器別アナリティクス画面を開く (`CombatStatsScreen`) |

---

## ビルド手順

Gradle Wrapper を使用してビルドします（Java 17 が必要です）：

```powershell
# 単体テストの実行
.\gradlew.bat test

# MOD jar のビルド (build/libs/taczindicator-1.0.1.jar が生成されます)
.\gradlew.bat build
```

---

## 導入方法
1. Minecraft Forge 1.20.1 (Forge 47.1.0以上、47.3.0推奨) をインストールします。
2. 生成された `build/libs/taczindicator-1.0.1.jar` を `.minecraft/mods` フォルダに配置します。
3. （任意）ゲーム内で `K` キーを押して好みの設定に調整します。
